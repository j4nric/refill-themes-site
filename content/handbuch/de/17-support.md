# Support

Fragen zum Theme beantworten wir über ein Formular. Hier steht, wie Sie eine Anfrage stellen, was der Support umfasst und wie schnell wir antworten.

## Support-Anfrage stellen

Stellen Sie Ihre Anfrage über das **[Support-Formular](https://refillthemes.freshdesk.com/support/tickets/new)**. Sie erhalten eine Eingangsbestätigung per E-Mail und alle Antworten an die Adresse, die Sie im Formular angeben.

Bitte geben Sie an:

- **Shop-Adresse**: Ihre Adresse `…myshopify.com`, nicht nur die eigene Domain.
- **Theme und Version**: zum Beispiel „Refill 0.9.0“. Die Version steht im Admin unter **Onlineshop → Themes** beim Theme.
- **Beschreibung**: Was Sie tun wollten, was Sie erwartet haben und was stattdessen passiert ist. Nennen Sie die betroffene Seite als Link. Tritt der Fehler nur am Handy oder in einem Browser auf, schreiben Sie das dazu.
- **Screenshots** oder eine kurze Bildschirmaufnahme, am besten mit geöffnetem Theme-Editor beim betroffenen Block oder Abschnitt.

Senden Sie keine Passwörter oder Zugänge zu Mitarbeiterkonten. Brauchen wir Zugriff auf Ihren Shop, fragen wir über eine Mitarbeiteranfrage (Collaborator) an.

Lädt das Formular nicht, schreiben Sie an [support@refill-themes.com](mailto:support@refill-themes.com).

## Support-Richtlinie

### Was der Support umfasst

Der Support ist im Preis des Themes enthalten. Er umfasst:

- **Fragen zu Einstellungen und Funktionen**: wie Sie Abschnitte, Blöcke, Theme-Einstellungen und Metafelder für Refill einrichten.
- **Fehler im Theme**: Etwas funktioniert nicht so, wie dieses Handbuch es beschreibt. Wir prüfen den Fehler im unveränderten Theme und beheben ihn in einem Update.
- **Updates**: Fragen zur Installation neuer Versionen und zu Änderungen aus dem [Änderungsprotokoll](16-changelog.md).

### Was der Support nicht umfasst

- **Individuelle Anpassungen**: neue Funktionen, geänderte Gestaltung oder Änderungen am Code für Ihren Shop. Solche Anpassungen sind nicht im Preis des Themes enthalten.
- **Apps von Drittanbietern**: Installation, Einrichtung und Fehler von Apps. Wenden Sie sich an den Anbieter der App. Wir helfen bei der Frage, ob ein Fehler am Theme oder an der App liegt.
- **Vom Händler geänderter Code**: Änderungen an Theme-Dateien und Code in **„Eigenes Liquid“**, siehe [Eigener Code und „Eigenes Liquid“](#eigener-code-und-eigenes-liquid).
- **Shopify selbst**: Zahlungen, Versand, Domains, Märkte und Ihr Shopify-Tarif. Dafür ist die [Shopify-Hilfe](https://help.shopify.com/de) zuständig.

### Antwortzeit

Wir antworten innerhalb von **2 Werktagen**. Werktage sind Montag bis Freitag. Anfragen beantworten wir in der Reihenfolge ihres Eingangs. Braucht ein Fehler länger, erhalten Sie innerhalb dieser Zeit eine erste Antwort und den nächsten Schritt.

### Sprache

Der Support antwortet auf **Deutsch** und **Englisch**.

## Eigener Code und „Eigenes Liquid“

Der Block und der Abschnitt **„Eigenes Liquid“** nehmen Liquid- und HTML-Code auf, zum Beispiel von Apps oder Agenturen. Refill unterstützt das Einfügen von Code an diesen Stellen. Den Code selbst deckt der Support nicht ab. Das gilt auch für Änderungen an den Theme-Dateien im Code-Editor.

So gehen Sie vor:

1. **Theme duplizieren**: Onlineshop → Themes → beim Theme **„…“ → „Duplizieren“**. Ändern Sie nur die Kopie.
2. Fügen Sie den Code ein und prüfen Sie die Seite in der Vorschau, am Handy und am Computer.
3. Veröffentlichen Sie die Kopie erst, wenn alles funktioniert.

Für Code-Anpassungen empfehlen wir einen **Shopify-Partner** aus dem [Shopify-Partnerverzeichnis](https://www.shopify.com/partners/directory).

Haben Sie Code geändert und vermuten einen Fehler im Theme? Prüfen Sie zuerst, ob er auch in einer unveränderten Kopie auftritt (Theme erneut aus dem Theme Store hinzufügen). Nennen Sie in Ihrer Anfrage, welcher Code geändert oder eingefügt wurde.

## Bevor Sie schreiben

Viele Fragen beantworten die [häufigen Fragen](15-faq.md), zum Beispiel wenn ein Block nicht erscheint oder ein Metafeld keinen Wert zeigt. Ob ein Fehler in einer neuen Version behoben ist, steht im [Änderungsprotokoll](16-changelog.md).
