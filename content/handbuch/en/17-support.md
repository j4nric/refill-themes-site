# Support

We answer questions about the theme through a form. This page explains how to submit a request, what support covers and how quickly we reply.

## Submit a support request

Submit your request using the **[support form](https://refillthemes.freshdesk.com/support/tickets/new)**. You receive a confirmation by e-mail, and all replies go to the address you enter in the form.

Please include:

- **Store address**: your `…myshopify.com` address, not only your own domain.
- **Theme and version**: for example “Refill 0.9.0”. The version is shown with the theme in the admin under **Online Store → Themes**.
- **Description**: what you wanted to do, what you expected and what happened instead. Add a link to the page concerned. If it only happens on phones or in one browser, please say so.
- **Screenshots** or a short screen recording, ideally with the theme editor open on the block or section concerned.

Do not send passwords or staff account access. If we need access to your store, we will ask for it with a collaborator request.

If the form does not load, write to [support@refill-themes.com](mailto:support@refill-themes.com).

## Support policy

### What support covers

Support is included in the price of the theme. It covers:

- **Questions about settings and features**: how to set up sections, blocks, theme settings and metafields for Refill.
- **Theme bugs**: something does not work as this guide describes. We check the bug in the unmodified theme and fix it in an update.
- **Updates**: questions about installing new versions and about changes listed in the [changelog](16-changelog.md).

### What support does not cover

- **Customizations**: new features, design changes or code changes for your store. Customizations are not included in the price of the theme.
- **Third-party apps**: installing, setting up and fixing apps. Please contact the app developer. We help you find out whether a problem comes from the theme or from the app.
- **Code changed by the merchant**: changes to theme files and code in **“Custom Liquid”**, see [Custom code and “Custom Liquid”](#custom-code-and-custom-liquid).
- **Shopify itself**: payments, shipping, domains, markets and your Shopify plan. For these, see the [Shopify Help Center](https://help.shopify.com/en).

### Response time

We reply within **2 business days**. Business days are Monday to Friday. We answer requests in the order they arrive. If a bug takes longer, you receive a first reply and the next step within this time.

### Languages

Support answers in **English** and **German**.

## Custom code and “Custom Liquid”

The **“Custom Liquid”** block and section accept Liquid and HTML code, for example from apps or agencies. Refill supports adding code in these places. Support does not cover the code itself. The same applies to changes to theme files in the code editor.

How to proceed:

1. **Duplicate the theme**: Online Store → Themes → **“…” → “Duplicate”** on the theme. Only change the copy.
2. Add the code and check the page in the preview, on a phone and on a computer.
3. Publish the copy only when everything works.

For code customizations, we recommend a **Shopify Partner** from the [Shopify Partner Directory](https://www.shopify.com/partners/directory).

Have you changed code and suspect a bug in the theme? First check whether it also happens in an unmodified copy (add the theme again from the Theme Store). In your request, say which code was changed or added.

## Before you contact us

Many questions are answered in the [FAQ](15-faq.md), for example when a block does not appear or a metafield shows no value. Whether a bug is fixed in a new version is listed in the [changelog](16-changelog.md).
